Goal + how it's calibrated
First race at ultra distance. UTMB index almost always drops a notch as distance rises — so 550–600 is the optimistic upper band if everything clicks, and landing a touch below it is still a fully successful first 91 k.
Real KPI: finish healthy and in control in 12–14 h. The index is an outcome of pacing well, not a target to chase from the gun.
Two risks, ranked: (1) quads blowing up on descents around 50–60 k; (2) GI failure from under-rehearsed fuelling in heat. Everything here serves one of those, plus not re-triggering the fatigue/LEA substrate.

Race-day pacing rules (first ultra)
First 50 km (most important)
HR cap 148, never above 152. First 30 k should feel "almost too easy" — that's the pacing, not a bug.
Power-hike anything ≥10% grade. No exceptions. Save the quads for the descents.
Bail-out trigger: HR drift >10 bpm at same pace → slow down.
50–80 km
HR cap relaxes to 158. Walk-run discipline through aid stations.
80–91 km
Run by feel. Empty the tank if anything's there.

What's NOT in the plan
  • No fast descending before the recce Build eccentric load by volume first; faster descents only from Build 4 on real terrain.
  • No heavy lifting Mon or Fri Mon = descent-DOMS day; Fri = pre-descent. Heavy work sits Wednesday.
  • No volume above the weekly ceiling Tissue tolerance, not available time, is the limiter off this base.
  • No iron supplementation Ferritin normal — no evidence base at this level.
  • No 5 K time trial Marathon already calibrates zones.
  • No Nordic hamstring curls Wrong stimulus for the actual cramp etiology.
  • No double thresholds Overkill for ultra goals.
  • No train-low / carb restriction Active LEA signal contraindicates.
  • No manufactured hills in Klaipeda Soft-sand dunes = ankle risk for no adaptation.
Weekly feedback loop (Sundays)

Each Sunday, send these five so the plan can load, hold, or back off:

  • Sessions done vs planned Strava auto-covers this.
  • Oura Avg sleep, readiness trend, any nights <7 h.
  • Subjective legs Fresh / normal / heavy — and how the descents felt.
  • Any niggle Hip / plantar especially, 0–3 scale.
  • Fuelling Hit the g/h target? Any GI issue?

Most important signal the next two weeks: does the heavy-legs-at-easy-pace feeling clear?

Adaptive principle

This is a default, not a contract. Every day, the question is: is the prescription today still right?

Good readiness + motivation → run the prescription.
Borderline → run at the easy end of the range.
Bad → swap quality for easy, swap long for medium, move by a day.
Show up consistently. Don't grind. For a first ultra off disrupted prep, arriving healthy is the whole goal — the index follows from that.
